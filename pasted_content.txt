## Design Direction

**Aesthetic:** Minimal, light, modern, premium artisan. Think: warm white and cream backgrounds, subtle pastel accents pulled from cookie icing colors (soft blush pink, sage green, pale lavender, butter yellow). Clean sans-serif typography paired with one elegant serif or script font for headings. Lots of whitespace. The site should feel like a high-end patisserie that also happens to be warm and community-rooted.

**Mood:** Joyful but refined. Not kitschy or cutesy — elevated and artisanal. Like if a Signal Mountain bakery got a Parisian rebrand.

**Color Palette:**
- Background: #FDFAF6 (warm off-white)
- Primary accent: #E8C5B0 (warm blush/peach)
- Secondary accent: #C8D8C0 (sage green)
- Text: #2C2C2C
- Highlight/CTA: #D4956A (warm terracotta)

**Typography:**
- Headings: Playfair Display or Cormorant Garamond (elegant serif)
- Body: Inter or DM Sans (clean, modern)
- Accent/script: Dancing Script or Pacifico for decorative elements only

## 3D Animations & Interactivity (Critical Requirement)

Use Three.js or React Three Fiber to implement the following interactive 3D elements. All animations must be smooth, performant, and feel premium — not gimmicky.

1. **Hero Section — Floating Cookie Scene:**
   A softly lit 3D scene with 3–5 stylized sugar cookie shapes (star, circle, heart, gingerbread man) gently floating and slowly rotating in 3D space. Cookies should have a frosted/iced pastel appearance with subtle specularity. Mouse movement should cause a gentle parallax tilt on the whole scene (the cookies drift slightly toward the cursor). On scroll, the cookies slowly drift upward and fade out.

2. **"Our Cookies" Section — 3D Cookie Reveal:**
   As the user scrolls into this section, a single large decorated cookie 3D model rotates into view from flat/edge-on to face-forward, as if being placed on a counter. Use scroll-linked animation (GSAP ScrollTrigger or equivalent). The cookie should have a glistening iced surface (normal/roughness map for realism).

3. **Ordering CTA — Sprinkle Particle System:**
   Behind or around the "Place an Order" call-to-action button, implement a subtle Three.js particle system that rains colorful sprinkle-like confetti particles slowly downward in 3D. Particles should be small elongated cylinders or flat discs in pastel colors. Keep it subtle — background atmosphere, not foreground chaos.

4. **Cursor Trail (Optional but preferred):**
   A gentle cookie-crumb or sprinkle particle trail that follows the cursor across the page with a short fade-out tail.

## Technical Requirements

- **Framework:** React (Vite) or plain HTML/CSS/JS — whichever produces cleaner output. React preferred for 3D component management.
- **3D:** Three.js directly, or React Three Fiber + Drei if using React.
- **Animation:** GSAP (with ScrollTrigger) for scroll-linked animations. Framer Motion acceptable for UI micro-interactions if using React.
- **No heavy UI libraries** (no Bootstrap, no MUI). Tailwind CSS is acceptable for layout utilities.
- **Fully responsive:** Mobile-first. All 3D elements must gracefully degrade or simplify on mobile (reduce poly count, disable cursor trail, simplify particle count).
- **Performance:** Lazy-load gallery images. 3D canvas elements should use `requestAnimationFrame` efficiently — pause when not in viewport using Intersection Observer.
- **Accessibility:** Semantic HTML, proper `alt` text on all images, keyboard-navigable nav, sufficient color contrast.
- **No placeholder lorem ipsum** — use real business copy from the information provided above.
